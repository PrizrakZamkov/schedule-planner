# Расписание

Планировщик недели, которым я пользуюсь сам.

Открыть: https://prizrakzamkov.github.io/schedule-planner/

## Что умеет

- Недельная сетка с 6:00 до 24:00. Задачу можно перетащить, растянуть за нижний край, скопировать через Alt или Ctrl+C / Ctrl+V.
- Задачи без времени лежат в отдельном списке. Кнопка Распланировать раскладывает их по свободным окнам.
- Повторы по дням недели и задачи на несколько дней.
- Шаблон недели: сохранить типичную неделю и применить к любой другой.
- Категории с цветами, отмена массовых действий, управление с клавиатуры.
- Экспорт и импорт в файл.

Всё хранится в localStorage браузера.

## Как работает автопланирование

Жадный алгоритм. Задачи сортируются по дедлайну, потом по приоритету, потом от длинных к коротким. Каждая занимает первое свободное окно с 9:00 до 21:00, начиная с текущего момента и не позже своего дедлайна. (В идеале использовать на малом количестве заданий)

Логика лежит в `src/lib/schedule.ts` и покрыта тестами.

## Запуск

```
npm install
npm run dev
npm test
```

Стек: React 19, TypeScript, Vite, Vitest. При пуше в main GitHub Actions прогоняет тесты, собирает проект и выкладывает на GitHub Pages по ссылке выше, если кому-то тоже пригодится.
