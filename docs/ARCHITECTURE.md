# Расписание — архитектура

Планер недели: задачи по часам, «Входящие», автопланирование, повторы, шаблон недели, категории.
Сервера нет. Всё работает в браузере, данные лежат в `localStorage` (ключ `schedule:v1`). Интерфейс только в тёмной теме.

## Стек и сборка

- React 19 + TypeScript, Vite, без UI-библиотек
- `vite-plugin-singlefile` собирает всё в один `dist/index.html`, его можно открыть двойным кликом
- Vitest для тестов логики (`src/lib/schedule.test.ts`)
- `.github/workflows/deploy.yml`: при пуше в `main` тесты, сборка и выкладка на GitHub Pages

Команды: `npm install`, `npm run dev`, `npm test`, `npm run build`.

## Структура

```
src/
  types.ts            модели: Task, Slot, Category, TemplateItem, PlannerState, Occurrence
  store.ts            useReducer + сохранение в localStorage, при первом запуске пустая неделя
  lib/time.ts         минуты, даты (ключи yyyy-mm-dd), неделя, форматирование, константы сетки
  lib/schedule.ts     чистая логика: пересечения, повторы, свободные окна, автоплан, шаблон
  lib/migrate.ts      normalizeState: дополняет старые сохранения и файлы недостающими полями, переводит цвета отменённого светлого дизайна обратно в тёмную палитру; PALETTE
  lib/cx.ts           склейка css-классов
  hooks/useTaskDrag.ts перетаскивание на Pointer Events (мышь и палец), перенос и растягивание
  components/         Header, WeekGrid, SpanStrip, TaskBlock, DraftBlock, Inbox (список «Задачи»), Categories, TaskModal, ContextMenu, Toast
  App.tsx             связывает всё: действия, отмена, шаблон, экспорт/импорт
  styles.css          все стили, переменные, тёмная тема, анимации
```

## Ключевые решения

- **Время хранится в минутах от полуночи**, дата строкой `yyyy-mm-dd`. Сравнение и сортировка простые, нет проблем с часовыми поясами.
- **Задача без `slot` = во «Входящих»**. Отдельного списка нет, это одно поле.
- **Повторяющаяся задача** хранится один раз: `repeat` (дни недели 0 = Пн) + `slot` (время и дата начала серии). На экран её разворачивает `occurrencesOn`. Выполнение отмечается по датам в `doneDates`.
- **Вся логика расписания в `lib/schedule.ts`** без React, поэтому она легко тестируется.
- **Состояние через `useReducer`**: все изменения описаны действиями в одном месте (`store.ts`).
- **Отмена**: перед массовым изменением App запоминает прошлое состояние, а тост с кнопкой «Отменить» возвращает его (`replace`).
- **Перетаскивание**: при движении ищем элемент под курсором (`elementFromPoint`) → колонка `[data-date]` или зона `[data-inbox]`. Позиция переводится в минуты и округляется до 15 минут.
- **Наложение задач разрешено.** Пересекающиеся задачи `layoutDay` раскладывает по «дорожкам»: группа пересекающихся делит ширину колонки поровну, свободная дорожка переиспользуется (как в Google Календаре).
- **Выделение области**: протянуть мышью по пустому месту дня → появляется `DraftBlock` с полем названия (Enter создаёт, Esc отменяет, «Подробнее» открывает полную форму). Клик без протягивания даёт блок на час. На телефоне работает тап, протягивание там прокручивает страницу.
- **Автопланирование** (жадный алгоритм): задачи из «Входящих» сортируются по дедлайну, затем по приоритету, затем от длинных к коротким. Каждая занимает первое свободное окно с 09:00 до 21:00, начиная с сегодня (не раньше текущего времени) и не позже дедлайна.
- **Шаблон недели** хранит блоки как «день недели + время». Применение пропускает блоки, которые пересекаются с уже занятым временем. Повторяющиеся задачи в шаблон не попадают, они и так повторяются.

## Ограничения (осознанно)

- Сетка показывает 06:00–24:00.
- Данные живут в одном браузере. Перенос между устройствами — через «Резервная копия → Скачать/Загрузить».

## Управление

- Протянуть по пустому месту или кликнуть → новая задача прямо в сетке. Клик по задаче → редактирование.
- Перетаскивание: из «Входящих» в календарь, по календарю, обратно во «Входящие». Нижний край задачи — изменить длительность.
- Копирование: Ctrl/Cmd+C на задаче под курсором, Ctrl/Cmd+V вставляет туда, где курсор (вне календаря — во «Входящие»). Перетаскивание с Alt создаёт копию. В окне задачи есть «Копировать» и «Дублировать» (копия сразу после оригинала). Копия всегда одиночная, даже из повторяющейся задачи (`copyTask`).
- Клавиатура на задаче: стрелки ↑↓ ±15 минут, ←→ ±день, Enter открыть, Пробел выполнено, Delete удалить (с отменой).

**Этап 8 (27.10–29.10.2026):** светлый редизайн сделан и **отменён по решению автора**, интерфейс снова тёмный, как в этапе 7. От редизайна осталось только невидимое:
- `lib/migrate.ts` → `normalizeState`: загрузка из localStorage и «Открыть файл» дополняют недостающие поля и никогда не теряют задачи; цвета категорий из отменённого светлого дизайна переводятся обратно в тёмную палитру того же оттенка, свои цвета не трогаются. Тест `migrate.test.ts`.
- Длинные слова в плашках не режутся: место под кружок «сделано» держит float-распорка.
- Ключ хранения `schedule:v1` не менялся ни разу с этапа 2.

**Этап 9 (29.10.2026): многодневные задачи.**
- Новое необязательное поле `task.span = { from, to }` (даты включительно). У таких задач `slot = null`; в списке «Задачи» и в автопланировании они не участвуют. Старые сохранения не меняются: поле добавляется только задачам, у которых оно есть (тест в `migrate.test.ts`).
- `lib/spans.ts`: `layoutSpans` раскладывает периоды недели по рядам и обрезает по краям недели (флаги `cutLeft/cutRight`), `shiftDate`, `spanDays`. Тесты `spans.test.ts`.
- `SpanStrip` — полоса «Весь день» внутри липкой шапки сетки: протянуть по пустому месту → поле названия; перетащить плашку → сдвиг по дням; края → растянуть; клик → окно задачи; кружок → сделано; правый клик → меню. За пределы недели мышью не тянется — для этого окно задачи (переключатель «Несколько дней», поля С/По).
- «Очистить неделю» удаляет периоды, которые целиком внутри недели. «Дублировать» ставит копию периода сразу после оригинала.
